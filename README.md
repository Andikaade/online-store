# Application Online Store

Aplikasi _e-commerce_ berbasis web yang dirancang untuk mengelola penjualan produk secara online secara efisien. Proyek ini mencakup alur lengkap toko online, mulai dari manajemen produk oleh admin, pendaftaran pengguna, proses _checkout_, hingga integrasi sistem pembayaran otomatis.

---

## 🛠️ Fitur Utama

### 🛒 Sisi Pengguna (User)

- **Autentikasi & Akun**: pendaftaran pengguna baru (_Register_) dan autentikasi (_Login_).
- **Katalog Produk**: Menjelajahi berbagai produk yang tersedia di toko.
- **Keranjang & Checkout**: Menambahkan produk ke keranjang belanja dan melakukan proses _checkout_ pesanan.
- **Integrasi Pembayaran (Midtrans)**: Transaksi pembayaran yang aman dan otomatis menggunakan _payment gateway_ Midtrans.
- **Riwayat Transaksi**: Memantau status pesanan dan riwayat transaksi yang pernah dilakukan.

### ⚙️ Sisi Pengelola (Admin)

- **Manajemen Produk (CRUD)**:
    - Tambah produk baru (_Add Product_)
    - Edit informasi produk (_Edit Product_)
    - Hapus produk (_Delete Product_)
- **Manajemen Pengguna**: Mengelola data pengguna (_User Management_).
- **Manajemen Transaksi**: Memantau dan mengelola seluruh transaksi pesanan masuk.

---

## 🚀 Teknologi yang Digunakan

- **Backend / Framework**: PHP / Laravel _(sesuaikan dengan yang kamu pakai)_
- **Database**: MySQL
- **Payment Gateway**: [Midtrans API](https://midtrans.com/)
- **Version Control**: Git & GitHub
